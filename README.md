# Samuel Lucas Blog

Site/blog profissional para autoridade em Gestão em Saúde, Dados, Inteligência Artificial e Oncologia.

## Stack

- Next.js
- TypeScript
- CSS global
- Deploy recomendado: Vercel

## Rodar localmente

```bash
npm install
npm run dev
```

## Identidade visual

Paleta inspirada na marca Sallus:

- Fundo papel: `#F8F5EE`
- Texto: `#1A1915`
- Laranja assinatura: `#DD560E`
- Verde Sallus: `#1FA37A`
- Azul técnico: `#2D5E80`
- Azul-marinho: `#0F2A44`
